# p99 design direction

The deployed homepage at https://p99.aauburn.com/ is the reference. Preserve its copy, including the headline “Reverse-engineer features from the apps that already won.” and supporting line “One app for each feature, plus a brief for your stack.” Do not rewrite these without the user's request.

## Homepage

Use the original white canvas, large centered headline, mono supporting text, 680px form, physical input surfaces and pill controls. Keep the pink robot and moving feature suggestions. The app input, feature label, suggestion hint and footnote use the deployed wording. No lilac enclosing panel or extra numbered labels.

The detailed app profile is the deliberate addition: a small **App details (optional)** control in the original action row. It starts collapsed and contains app name, platform, stack, integration notes and package.json. Users can search with a link or short description and selected features. Account and Premium navigation remain available.

## Results

Keep the established visual style and headline. Put app choice and the brief action first. Let users open supporting evidence instead of repeating excerpts, metrics and explanatory paragraphs on the main screen. Preserve source links, dates, confidence context and useful empty states.
